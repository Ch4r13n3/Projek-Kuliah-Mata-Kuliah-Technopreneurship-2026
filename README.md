# Proyek Kuliah Mata Kuliah Technopreneurship 2026
## 📱 Nama Produk: GlowDiary (atau nama aplikasi pilihanmu)

## 📌 1. Problem (Permasalahan)
* Masalah utama yang dihadapi pengguna terkait skincare (misal: bingung menentukan tipe kulit, kesulitan tracking perkembangan kecocokan produk, atau banyaknya produk palsu/tidak aman).
* Mengapa masalah ini penting untuk diselesaikan?

## 💡 2. Solution (Solusi)
* Bagaimana aplikasi web ini menyelesaikan masalah di atas? (misal: menyediakan fitur diary harian untuk memantau kondisi kulit, kuesioner pintar untuk analisis tipe kulit, dan laporan perkembangan kulit).

## 👥 3. Target Pasar (Target Audience)
* Siapa pengguna utama aplikasi ini? (misal: remaja, antusias skincare, orang dengan masalah kulit spesifik).

## 🚀 4. Fitur Utama Aplikasi (Sesuai Struktur File)
* **Landing Page (`landing.html`)**: Halaman utama yang mengenalkan produk dan menarik pengguna untuk mendaftar.
* **Kuesioner (`kuesioner.html`)**: Fitur untuk menganalisis kondisi atau jenis kulit awal pengguna.
* **GlowDiary (`glowdiary.html`)**: Jurnal harian untuk mencatat produk yang digunakan dan kondisi kulit harian.
* **Profil Pengguna (`profile.html`)**: Halaman informasi pribadi dan preferensi jenis kulit pengguna.
* **Skin Report (`skin_report.html`)**: Halaman analisis visual atau laporan perkembangan kulit dari waktu ke waktu.

## 🛠️ 5. Teknologi yang Digunakan
* HTML5 / CSS3
* JavaScript (jika ada interaktivitas atau pengolahan data kuesioner)
* Framework CSS (seperti Tailwind atau Bootstrap, jika digunakan)
